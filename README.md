# HÜTTENKLANG – Nicht ganz normal

Privater Albumplayer für sieben Hüttenklang-Songs, umgesetzt als statische GitHub-Pages-Webseite.

## Dateien

- `index.html` – responsiver Player mit Titelliste, Zufall und Wiederholung
- `cover.jpg` – originales Hüttenklang-Logo
- `audio/01.m4a` bis `audio/07.m4a` – sieben Albumtitel

**Wichtig:** Das Cover und die Audiodateien müssen noch hochgeladen werden. Sie sind nicht Bestandteil des aktuellen Commits.

## GitHub Pages

In den Repository-Einstellungen unter **Settings → Pages** als Quelle **Deploy from a branch**, Branch `main`, Verzeichnis `/(root)` auswählen. Nach Aktivierung: https://ricfritzsche89.github.io/h-ttenklang/
